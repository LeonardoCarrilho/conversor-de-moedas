    Como funciona

    Cotação em cascata

    A API entrega cada moeda em relação ao real. Qualquer outro par, como dólar para euro, é obtido dividindo as duas taxas — sem depender de uma cotação específica para cada combinação.

    Cache de 15 minutos

    As cotações ficam salvas no localStorage com data e hora. Se a API falhar ou você estiver offline, o conversor continua funcionando com a última tabela conhecida.

    Nada de chave secreta

    A AwesomeAPI é pública e não exige token. O projeto é 100% estático: não há back-end, banco ou variável de ambiente para configurar.

    Valores de referência

    Na primeira visita sem internet, o app usa uma tabela embutida e avisa que os valores são de referência, nunca apresentando dados antigos como se fossem atuais.
